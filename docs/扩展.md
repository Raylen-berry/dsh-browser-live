# 接入日常 Chrome 与 Edge

[返回首页](../README.md) · [文档导航](README.md)

需要日常浏览器里已有的登录态、代理或扩展时，使用本页流程。插件独立实例不需要安装这个扩展。

## 连接步骤

1. 在 **设置 → 浏览器观察窗 → 用户浏览器桥** 开启桥，复制页面显示的 token。
2. 在要接入的浏览器中打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式。
3. 选择「加载已解压的扩展程序」，加载本仓库的 **`extension/`** 目录。
4. 点击浏览器工具栏的 DSH Browser Bridge 图标，粘贴 token，点「连接」。
5. 在扩展弹窗里对要使用的站点点「允许」；需要点击、输入、滚动或上传时，再打开「允许操作」。

Chrome 和 Edge 可各装一份，同时连接同一个本地桥；两边用同一个 token，站点授权和开关各自保存。

也可让模型调用 `browser_ext_setup` 准备现场：开启桥、把 token 复制到剪贴板、打开目标浏览器扩展页及扩展目录。加载扩展、连接和站点授权仍需你在浏览器里完成。

## 这些开关有什么区别

| 开关 | 含义 |
| --- | --- |
| 站点「允许」 | 允许该来源下的页面被读取和连接；未授权站点的标题、URL 对模型隐藏 |
| 允许操作 | 默认关闭；打开后才可点击、输入、滚轮和上传 |
| 允许 agent 新开标签页 | 控制模型新开页面；新开的站点仍需授权才能读取 |
| 允许关闭 agent 自己打开的标签页 | 控制模型关闭自己新开的页；手动打开的页不在关闭范围内 |
| 允许当前所有标签页 | 批量授权目前打开的站点，不等于授权未来所有网站 |
| 允许所有网站 | 放开逐站点限制，范围比当前标签页授权更大 |
| 脚本登记表 | 控制登记脚本的加载方式；临时编写的任意表达式不等于可执行脚本 |

默认只读仍包含导航、刷新和读取，不表示网页完全保持原状。输入操作会尝试把目标标签和浏览器窗口切到前台；只读截图与文字读取不会因此抢前台。

## 指定用哪台浏览器

模型工具的 `use` 参数可以明确选择：

| 值 | 使用哪一种 |
| --- | --- |
| `plugin` | 插件独立实例 |
| `edge` / `chrome` | 对应的日常浏览器，必须已连接 |
| `user` | 配置的默认日常浏览器，或已连接的一台 |
| `auto` | 有日常浏览器连接时使用它，否则用独立实例 |
| 省略 | 沿用上一次工具调用的浏览器；首次按后端设置，默认独立实例 |

例如：`browser_open { use: "edge", url: "…" }` 选择 Edge；`browser_open { use: "plugin" }` 切回独立实例。工具结果和观察窗标识会显示实际使用的浏览器。

显式指定 Edge 或 Chrome 但未连接时会报错。仅沿用上一次浏览器、而那台已掉线时，才可能退回独立实例，并显示动作提示；需要已有登录态的任务应明确指定目标。

## 断开与更新

`browser_close` 在日常浏览器模式下断开调试器，保留浏览器；关闭标签页只能作用于模型自己创建且获准关闭的页面。

扩展文件更新后，在 Chrome 和 Edge 的扩展页分别点「重新加载」。浏览器自己的“正在调试”横幅无法由插件隐藏。

更完整的扩展说明见 [extension/README.md](../extension/README.md)，桥协议和旧接管记录见[历史](历史.md)。
