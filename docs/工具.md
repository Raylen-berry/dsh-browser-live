# 浏览器工具

[返回首页](../README.md) · [文档导航](README.md)

工具由模型调用；普通使用可直接描述网页任务。每次调用都可用 `use` 选择浏览器，取值见[扩展](扩展.md)。

## 打开、切换与关闭

| 工具 | 用途 |
| --- | --- |
| `browser_open` | 启动或接入浏览器，打开 URL，可新建标签 |
| `browser_ext_setup` | 准备日常浏览器扩展的安装与连接现场 |
| `browser_close` | 关闭独立实例，或断开日常浏览器调试连接 |
| `browser_tabs` | 列出、新建、选择或关闭标签；日常浏览器受扩展开关限制 |
| `browser_navigate` | 导航到指定 URL 并等待加载 |
| `browser_history` | 前进、后退、刷新 |

## 看、读、抓、搜

| 工具 | 用途 |
| --- | --- |
| `browser_snapshot` | 查看可交互元素、文字、状态和引用 ID，用于判断下一步 |
| `browser_read` | 按结构提取正文为 Markdown，支持段落感知续读 |
| `browser_text` | 提取纯文字，按字符分块 |
| `browser_scrape` | 根据重复结构及字段规则提取行数据 |
| `browser_search` | 在真实浏览器中搜索，返回结果和拦截等状态 |
| `browser_wait` | 等待文字、元素、URL 条件或指定时间 |
| `browser_eval` | 执行页面表达式；日常浏览器受脚本登记机制限制 |

点击前先读取新快照；页面重排或跳转后，旧引用可能失效，应重新观察。长文与大结果有长度上限，返回截断信息和续读提示，不保证一次包含全部内容。

## 操作页面与文件

| 工具 | 用途 |
| --- | --- |
| `browser_click` | 点击引用、选择器或坐标，支持双击与右键 |
| `browser_move` | 移动鼠标、触发悬停，支持按住左键 |
| `browser_type` | 输入文字并回读字段值，支持回车 |
| `browser_upload` | 向文件输入控件设置本机文件 |
| `browser_press` | 发送按键或组合键 |
| `browser_scroll` | 按方向和距离滚动 |
| `browser_downloads` | 查看下载记录；两种模式的文件取回范围不同 |

## 截图与像素比对

| 工具 | 用途 |
| --- | --- |
| `browser_screenshot` | 保存可视区或整页 PNG |
| `browser_pixel_diff` | 将当前页面截图与基准 PNG 比较；基准不存在时先创建 |
| `browser_pixel_compare` | 比较两张已有 PNG，不再访问页面截图 |

像素比对可对不同尺寸做归一化，并输出统计和差异图；它衡量画面差异，不解释差异的业务含义。首次创建基准不等于通过了一次回归比对。

正文类字段单次上限为 20,000 字符，整个工具结果上限为 24,000 字符；快照元素、抓取行和搜索结果另有数量额度。具体参数、截断字段以当前工具声明和返回值为准。
