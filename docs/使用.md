# 使用观察窗

[返回首页](../README.md) · [文档导航](README.md)

模型操作网页时，你可以观察进度，或临时亲手操作同一个受控页面。第一轮通常使用插件独立实例；已有登录态的页面可改用[日常浏览器](扩展.md)。

## 窗口里能做什么

| 控件或显示 | 用途 |
| --- | --- |
| 侧栏 🌐 | 打开观察窗 |
| 标签条 | 查看、切换受控标签页 |
| 最近动作 | 查看模型刚执行的工具动作 |
| 画质与 FPS | 调整观察画面的清晰度与刷新频率 |
| 标题栏与宽屏 | 拖动内嵌面板、贴边或调整阅读面积 |
| 独立观察页 | 将 `/bl/view` 放到新窗口或副屏 |
| 下载入口 | 取回独立实例产生的下载文件 |
| ✕ | 收起观察窗，浏览器任务仍可继续 |
| ⏹ 关浏览器 | 结束当前浏览器连接；独立实例会关闭，日常浏览器只断开调试连接 |

模型首次启动浏览器时会自动显示一次观察窗。你主动收起后，同一页面生命周期内不会每一步都重新弹出。

## 人工接管

需要登录、验证码或页面人工操作时，先让模型暂停，再在观察窗或实际受控浏览器里完成。结束后告诉模型继续，避免双方同时输入。

观察窗中的鼠标、滚轮和键盘会转发给受控页面。日常浏览器仍受扩展的站点授权和「允许操作」约束；观察窗不能绕过这些开关。

插件的鼠标轨迹作用于网页输入事件，不会移动 Windows 的系统光标。把 FPS 调高主要改善观察画面的刷新，不会让模型推理更快。

## 可以这样提任务

| 任务 | 示例 |
| --- | --- |
| 读网页 | “用插件独立浏览器打开我提供的网页，读取正文并列出主要结论。” |
| 整理列表 | “读取这个页面的列表，把标题、日期和链接整理成表格。” |
| 使用已有登录态 | “使用已连接的 Edge 读取我授权站点的当前页面。” |
| 准备表单 | “把这些内容填入表单，填好后停下让我检查。” |
| 检查页面变化 | “保存修改前后的截图，对比像素差异，并说明差异位置。” |

需要指定浏览器时，明确告诉模型使用独立实例、Edge 或 Chrome；具体参数和工具见[扩展](扩展.md)与[工具](工具.md)。

## 结束任务与边界

用完可让模型关闭浏览器，或点「⏹ 关浏览器」。关闭独立实例后 profile 保留，下次可继续使用其登录态；日常浏览器不会因此整窗关闭。

受控状态按浏览器区分，但不为每个 DSH 会话提供独立浏览器。多个模型任务同时操作同一浏览器会争用标签页，应安排先后顺序。

上传支持文件输入控件及部分自定义包裹组件；纯拖放区域或跨域 iframe 内操作不保证支持。模型主要依据页面结构与文字判断；截图和像素差异只能作为辅助信息，不能代替任务结果核对。
