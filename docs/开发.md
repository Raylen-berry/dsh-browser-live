## 检查入口

需要 Node.js 22 或更高版本，测试依赖按锁文件安装：

```powershell
npm ci --ignore-scripts
npm test
node tools/run-all.mjs --list
```

完整入口包含语法、桥隔离、扩展权限、启动器、结果上限、留痕、面板状态、截图回收与像素比对。逐套件条数以 `npm test` 输出为准；清单以 [run-all.mjs](../tools/run-all.mjs) 为准。

运行前将 `DSH_HOME` 指向独立测试目录，让默认的留痕校验不读取个人数据。总入口的离线套件使用本机模拟服务和测试夹具，不发真实模型请求，也不执行真实网页任务。

总入口排除真实 Chromium 的 host、页面函数与网页工具检查，以及需要已有截图的探针。手动执行这些脚本前先查看各自环境要求；一次离线通过不代表已完成真实浏览器或站点验收。

CI 使用 Windows、Node.js 22／24，见 [ci.yml](../.github/workflows/ci.yml)。测试中的文档校验要求首页保留检查清单、调用技能数量和「版本与变更记录」锚点，整理时应保持事实准确。

## 接口与分发

观察窗接口统一在 `/bl/*` 下：设置、状态、帧流、输入、标签、下载、桥状态和独立观察页。入口定义以 [index.js](../index.js) 为准；多浏览器桥协议保留在[历史目录](历史.md)中。

运行时只使用宿主能力和系统浏览器；`ws` 是测试依赖。发布清单需覆盖宿主引用的 `view-page.js`、其他模块、扩展、技能和文档，可用 `npm pack --dry-run --ignore-scripts` 查看。

改插件代码后完整重启 DSH Desktop，改扩展后分别重新加载。来源与许可见 [NOTICE](../NOTICE)、[LICENSE](../LICENSE)。
