# 安装与常见问题

[返回首页](../README.md) · [文档导航](README.md)

## 准备条件

需要 DSH Desktop，且 `git`、`dsh` 命令可用。本项目主要在 Windows 上验证，独立实例需要本机已安装 Chrome、Edge 或 Brave。

接入日常浏览器还需要加载本仓库的 MV3 扩展；普通独立实例无需这一步。两种模式共用同一插件，详见[扩展](扩展.md)。

## 安装

等正在执行的任务结束，关闭 DSH Desktop。以下目录是示例，可替换为自己的绝对路径：

```powershell
git clone https://github.com/Raylen-berry/dsh-browser-live.git D:\dsh-plugins\dsh-browser-live
dsh plugin --profile web add link:D:/dsh-plugins/dsh-browser-live
```

重启 DSH Desktop，在「设置 → 插件」检查启用状态。侧栏应出现 **🌐 浏览器观察窗**，设置中应有「浏览器观察窗」页面。

首次执行浏览器工具时才启动或连接浏览器，不需要为了安装先启动一个网页任务。

## 更新

在插件目录先检查自己的修改；处理好后执行 `git pull --ff-only`，等任务结束再完整重启 DSH Desktop。日常浏览器的扩展文件更新后，还需在各自的扩展管理页点「重新加载」。

开发用 Node.js 要求 22 或更高版本；运行插件使用的依赖由 DSH 宿主提供。测试依赖安装见[开发](开发.md)。

## 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 没有 🌐 或设置入口 | 是否启用、是否装到 `web` profile、安装后是否完整重启 |
| 独立浏览器起不来 | 本机浏览器是否存在，设置中的路径是否有效；启动器会尝试其他可用候选 |
| 明明登录过，任务又要求登录 | 独立实例与日常浏览器的登录态分开，确认当前用的是哪一种 |
| 扩展装好了，但无法接入 | 先启用用户浏览器桥，再在对应扩展中连接，见[扩展](扩展.md) |
| 能看页面，无法点击输入 | 在该浏览器扩展里授权当前站点，再打开「允许操作」 |
| 日常浏览器操作没有响应 | 输入时需标签页激活、窗口获得焦点；Windows 拒绝切换前台时需手动点窗口 |
| 观察窗画面不更新 | 查看连接和画面状态，确认浏览器未关闭；独立观察页被拦时可用内嵌面板 |
| 改了代理还走旧配置 | 独立浏览器需关闭后重新启动，见[设置](设置.md) |

如果日志出现 `migration deferred`、`could not stage` 或安装路径 `ENOENT`，需检查宿主的插件迁移状态。历史说明中的本机补丁不包含在本仓库内，不能把旧机器路径直接当作本机修复步骤。
