# 设置与生效时间

[返回首页](../README.md) · [文档导航](README.md)

入口：**设置 → 浏览器观察窗**。一般先使用默认值；参数帮助调整观察效果和独立浏览器的启动方式。

| 设置 | 默认或范围 | 作用 |
| --- | --- | --- |
| 观察窗形态 | 内嵌面板 | 可改为独立观察页，适合副屏 |
| FPS | 默认 2，范围 0.5–10 | 观察画面的刷新频率 |
| 画质 | 默认 60，范围 20–90 | JPEG 帧质量 |
| 面板宽／高／宽屏宽 | 默认 42%／52%／66% | 相对于 DSH 视口的比例 |
| 浏览器窗口尺寸 | 默认 `1440,900` | 像素尺寸，也支持 `80%,85%` 等工作区比例 |
| 无头模式 | 默认关闭 | 不显示独立浏览器窗口，观察窗仍可看到渲染页面 |
| 浏览器路径 | 默认自动探测 | 指定独立实例使用的程序 |
| 代理和额外参数 | 默认空 | 独立实例的启动参数；日常浏览器沿用自己的配置 |
| 拟人轨迹与速度 | 默认开启，速度 1 | 模型鼠标事件的轨迹；人工接管保持即时 |
| 用户浏览器桥 | 默认关闭 | 接入浏览器扩展 |
| 后端模式／默认日常浏览器 | 默认 `auto`／`edge` | 冷启动选择与 `use:"user"` 的偏好 |

`backendMode: auto` 的初始默认是独立实例；工具显式传 `use:"auto"` 则会优先使用已连接的日常浏览器。两者不要混淆，具体选择规则见[扩展](扩展.md)。

## 哪些改动需要重新打开

观察画质、面板和形态可在当前界面调整。代理、浏览器路径、窗口和额外启动参数属于启动条件，对已经运行的独立实例需关闭后再启动才能生效。

安装或更新插件代码需要完整重启 DSH Desktop；更新浏览器扩展文件需要在扩展管理页重新加载。

## 进阶设置

设置保存在 `settings.json`，可用 `node tools/settings.mjs show` 查看生效值。搜索引擎定义、尝试顺序、冷却和总预算可在该文件中配置；不在页面中的参数以源码校验范围为准。

面板尺寸比例针对观察窗，浏览器窗口比例针对屏幕工作区；这两个值并不控制同一个区域。拟人轨迹只改变网页收到的输入事件，不移动系统光标，也不保证绕过站点检测。
