# 浏览器观察窗

让 DSH 中的模型操作本机真实浏览器，**你在观察窗里看见每一步，也可以亲手操作同一个页面**。适合读取动态网页、整理列表、填写表单，以及需要登录后才能访问的任务。

插件名 `dsh-browser-live` · 入口 **侧栏 🌐** · 设置 **设置 → 浏览器观察窗**

[安装](docs/安装.md) · [开始使用](docs/使用.md) · [接入日常浏览器](docs/扩展.md) · [文档导航](docs/README.md)

## 可以做什么

| 功能 | 具体用途 |
| --- | --- |
| **看见模型的操作** | 观察当前页面、标签页和最近动作；需要时接管鼠标键盘 |
| **读、抓、搜** | 读取正文，提取列表和表格，在真实浏览器中搜索 |
| **处理网页任务** | 点击、输入、滚动、上传文件，查看下载记录 |
| **使用已有登录态** | 通过扩展接入你日常使用的 Chrome／Edge，按站点授权 |
| **截图与对比** | 保存页面截图，比较两张 PNG 的像素变化 |

## 先选哪种浏览器

| 用法 | 适合什么 | 需要准备什么 |
| --- | --- | --- |
| **插件独立实例** | 普通网页任务，或愿意在独立浏览器里登录 | 安装插件和本机 Chrome／Edge／Brave；无需桥扩展 |
| **日常 Chrome／Edge** | 需要你已有的登录状态、代理或浏览器扩展 | 加载本仓库的浏览器扩展、连接本地桥，并授权站点 |

首次使用默认走独立实例，登录状态与日常浏览器分开。Chrome 和 Edge 可以同时接入，但各自安装扩展、各自授权。两种用法见[使用](docs/使用.md)与[扩展](docs/扩展.md)。

## 第一次使用

1. 按[安装说明](docs/安装.md)安装，等正在执行的任务结束后重启 DSH Desktop。
2. 在会话中发送：**“用插件独立浏览器打开我提供的网页，读取正文并总结。”**
3. 点击侧栏 **🌐** 查看观察窗；也可在标题栏切到独立观察页，方便放到副屏。
4. 遇到登录或验证码时，先让模型暂停，你在受控页面完成操作后再继续。

接入日常浏览器时，扩展默认只读；点击、输入、上传还需打开「允许操作」。这个只读档仍允许导航，不表示页面一定完全不变。

观察窗关闭只收起画面；结束独立浏览器任务时，使用「⏹ 关浏览器」或让模型调用关闭工具。模型之间共用插件的浏览器状态，同时执行网页任务应协调使用。
